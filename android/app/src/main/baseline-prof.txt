# Swahn Chat baseline profile -- HAND-WRITTEN, not measured.
#
# What it is: rules in the ART profile text format (flags H = hot, S = startup, P = post startup, L = the class itself; a rule with a
# wildcard matches every method/class of that name pattern). The Android Gradle plugin compiles this file into assets/dexopt/baseline.prof
# of the release and qa APKs (debug builds do not carry it), and androidx.profileinstaller hands it to ART when the app is installed, so that
# the code below is compiled ahead of time instead of being interpreted and JIT-compiled on first use.
#
# Why wildcards: a measured profile needs a Macrobenchmark run on a device or emulator, which this repository does not have yet (see
# docs/ARCHITECTURE.md and HANDOVER.md, "Baseline profile", for how to generate one and replace this file). Until then the rules cover the
# paths that every start walks: application start and the Hilt graph, the Room database and its DAOs, the conversation list, opening a chat
# and sending a message, and the Compose / lifecycle / navigation / paging code those screens run on.
